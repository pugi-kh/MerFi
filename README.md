# MerFi

파일명 패턴으로 자동 폴더 정리.

## 실행

```bash
python MerFi.py
```

## 사용

폴더 경로 입력 → 확장자 입력 → 폴더명 생성 방식 선택

**폴더명 생성 방식**
- 범위 지정: 파일명의 N번째~M번째 자리로 폴더명 생성
- 직접 입력: 폴더명 직접 작성 (여러 개는 `/`로 구분)

폴더명 확인 후 실행.
